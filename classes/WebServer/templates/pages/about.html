About MPG

Multi Protocol Gateway (MPG) is an open-source data-collection middleware designed for home energy systems. It bridges low-level hardware communication protocols (Modbus TCP/RTU over RS485) with modern data infrastructure (MQTT for Home Assistant, TimescaleDB and InfluxDB for long-term analytics).

MPG supports multiple simultaneous scraper transports, each targeting a different device (inverters, battery management systems), and multiple bridge transports that receive and forward the collected metrics. All transports operate in configurable read modes: sequential, concurrent, or interleaved.

This Web Management UI provides a browser-based interface for inspecting and editing the gateway configuration without touching raw config files. All changes are staged in a local SQLite database and only written to disk text files when you explicitly commit.

  • Configure scrapers and bridges via a guided UI
  • Browse and toggle protocol register maps (mask / screen / write-back)
  • Track staged vs committed state with a visual diff
  • Auto-detect orphaned settings after code changes
  • Versioned config.cfg backups with one-click rollback
