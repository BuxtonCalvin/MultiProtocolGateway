# SolArk to MQTT

Currently untested / unconfirmed. mpg version 1.1.3 and higher

## Hardware

1. USB to RS485 Adapter & RJ45 Ethernet cable ( or 3 wires )
2. Connect RJ45 ethernet cable to an available RS485/Modbus port:
3. Connect appropriate wires to USB RS485 Adapter. see sol ark documentation

![image](https://github.com/BuxtonCalvin/MultiProtocolGateway/assets/2180145/1d14a542-25ab-4233-917b-304c5bfe2ef2)

## Configuration

Follow configuration example for ModBus RTU to MQTT
<https://github.com/BuxtonCalvin/MultiProtocolGateway/wiki/Configuration-Examples#modbus-rtu-to-mqtt>

``` ini
protocol_version = solark_v1.1
```
